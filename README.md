## ✨ Что умеет Gemini в режиме Antigravity

- 🌐 **Браузерная автоматизация (`browser-control`):**
  - Открытие сайтов и навигация по вкладкам.
  - Нажатие на элементы, заполнение поисковых строк и форм.
  - Анализ содержимого страниц и создание веб-скриншотов.

- 🖥️ **Полный контроль рабочего стола (`windows-pc`):**
  - Перемещение мыши, одиночные и двойные клики по координатам или именам элементов.
  - Ввод текста и системные горячие клавиши (`Ctrl+C`, `Alt+Tab`, `Win+R` и др.).
  - Снятие скриншотов активных окон или всего экрана для визуального анализа.
  - Запуск любых программ и выполнение команд PowerShell.

- 📁 **Работа с файлами (`filesystem`):**
  - Создание, редактирование, построчное чтение и поиск кода/документов на диске.

## ⚡ Быстрый старт за 2 минуты

### 1. Требования
- Установленный **[Node.js](https://nodejs.org/)** (v18 или новее).
- Для Windows-модуля управления рабочим столом рекомендуется менеджер пакетов **uv**:
  ```powershell
  winget install astral-sh.uv
  ```

### 2. Проверка окружения
В папке проекта дважды кликните по файлу `run.bat` (или запустите в терминале):
```bash
npm run check
```
Скрипт автоматически проверит доступность всех утилит и конфигураций.

## 🕹️ Способы подключения к Gemini

### Вариант A. Прямо в браузере (gemini.google.com)

1. Установите расширение для Chrome: **[MCP SuperAssistant](https://chromewebstore.google.com/)**.
2. Запустите мост двойным кликом по `start-bridge.bat` (или в терминале):
   ```bash
   npm start -- --start-host
   ```
3. В настройках расширения укажите путь к конфигу:
   `config/mcp_config.json`.
4. Откройте [gemini.google.com](https://gemini.google.com/) — в чате появятся доступные инструменты MCP! Теперь вы можете просить Gemini:
   - *"Открой браузер и найди информацию о..."*
   - *"Сделай скриншот экрана и опиши, что открыто"*
   - *"Создай файл проекта на моем рабочем столе"*

---

### Вариант B. В автономных агентских клиентах

Если вы используете **Goose AI**, **Cline**, **Roo Code** или **Gemini CLI**:

1. Откройте файл `config/mcp_config.json`.
2. Скопируйте блок `"mcpServers"` в настройки вашего клиента.
3. Укажите бесплатный ключ **Google Gemini API** (получается за 1 минуту в [Google AI Studio](https://aistudio.google.com/)).

## 🔒 Безопасность

- **Подтверждение действий:** Для критических операций (удаление файлов, выполнение деструктивных системных скриптов) держите включенным режим запроса подтверждения в вашем MCP-клиенте.
- **Изоляция директорий:** По умолчанию `filesystem` настроен на текущую папку проекта (`.`). Если вы хотите дать доступ к другим дискам, отредактируйте аргументы в `config/mcp_config.json`.
